# Preparar ramas, commits o PR de Joyería Sole cuando la tarea lo requiera.

Leer [AGENTS.md](../../../AGENTS.md) y la [referencia del área](../../../.claude/skills/git-workflow/SKILL.md). Las rutas de código que esa referencia presenta se resuelven desde la raíz del repositorio.

Comprobar HEAD, ramas y remoto antes de asumir develop u origin. La autorización de configuración no autoriza commit o push. Utilizar las skills de Git del cliente cuando estén disponibles.

Aplicar la referencia dentro del alcance autorizado. Las aprobaciones ya dadas siguen vigentes; solicitar únicamente decisiones realmente faltantes. Entregar archivos afectados, evidencia, comprobaciones ejecutadas y limitaciones.
