# Entrega de tareas

Leer [AGENTS.md](../../../AGENTS.md), [HARNESS.md](../../../docs/engineering/HARNESS.md) y usar la [plantilla de tarea](../../../docs/engineering/TASK-TEMPLATE.md) para trabajo sustancial.

Descomponer por comportamiento verificable, no por cantidad de archivos. Identificar P-xx bloqueantes y continuar partes independientes. Elegir solo las skills del área. Si se delega dentro de la autorización vigente, asignar objetivo, archivos, dependencias, pruebas y entrega; evitar escrituras compartidas.

Antes del cierre comparar aceptación contra evidencia real, revisar regresiones y anotar límites. Cambios pequeños no necesitan crear documentos vacíos ni activar todos los roles. Ante una diferencia entre instrucciones y código, explicar cuál es requisito y cuál es estado observado.
