# Plantilla de tarea

Copiar para tareas sustanciales. Completar antes de implementar; no guardar campos vacíos como tarea lista.

- **ID y título:** identificador estable y comportamiento concreto.
- **Objetivo y requisito:** beneficio para la tienda, enlace a dominio/ADR/P-xx aprobado.
- **Estado:** propuesta / lista / en curso / bloqueada / en revisión / terminada.
- **Prioridad y riesgo:** urgencia, impacto y probabilidad razonados.
- **Responsable y revisor:** roles; un único responsable de integración.
- **Alcance:** comportamiento incluido y límites relevantes.
- **Dependencias:** tareas, decisión del cliente, contrato o infraestructura necesaria.
- **Archivos previstos:** rutas de escritura; acordar propietario de archivos compartidos.
- **Aceptación:** casos Dado/Cuando/Entonces observables, incluidos errores y permisos.
- **Verificación:** pruebas y comandos, entorno aislado y datos necesarios.
- **Evidencia:** fecha, revisión o huella del árbol si no hay commit, comando, código de salida, resultado; sin credenciales.
- **Recuperación:** cómo deshacer código; para datos, migración compensatoria o restauración ensayada.
- **Cierre:** aceptación comprobada, revisión, documentos actualizados y riesgos restantes.
